# Duplicate File Removal Automation

## 1. Project Title

**Auto Disk Cleaner** (Duplicate File Removal Automation)

## 2. Project Description

This project is a Python automation script that periodically scans a specified
directory, detects duplicate files using MD5 checksums, deletes the duplicate
copies (keeping one original from each group), generates a detailed timestamped
log file, and sends that log file through email. It also removes any completely
empty (0-byte) files it finds along the way.

The script runs continuously in the background, repeating the scan-and-clean
operation at a user-defined interval (in minutes), until manually stopped.

## 3. Features

- Recursive directory scanning (scans all sub-folders, not just the top level)
- Checksum-based duplicate detection (MD5) — compares file **content**, not filenames
- Automatic duplicate-file deletion (keeps the first file in each duplicate group)
- Empty-file cleanup (deletes 0-byte files)
- Timestamp-based log file generation for every run
- Periodic execution using the `schedule` library
- Email notification after every run, with the log file attached
- Input validation for directory path, time interval, and email address
- Exception handling around file I/O, permissions, and network/SMTP errors
- Modular programming — all reusable functions live in a separate utility module

## 4. Requirements

- **Python version:** 3.8 or higher
- **Required Python libraries:**
  - `schedule` (install via `pip install schedule`)
  - `hashlib`, `os`, `sys`, `time`, `datetime`, `smtplib`, `email` — all part of
    the Python standard library, no installation needed
- **Internet connection** — required for sending the log-report email
- **Gmail App Password** — required for SMTP authentication (a regular Gmail
  account password will not work; see Section 11)

## 5. Project Structure

```
DuplicateFileRemoval/
│
├── Auto_Disk_Cleaner.py          # Driver script — entry point, argument
│                                   parsing, validation, and scheduling
│
├── DuplicateFileRemovalUtils.py  # Utility module — all reusable functions:
│                                   DeleteEmpty, CalculateCheckSum,
│                                   FindDuplicate, DeleteDuplicate, SendMail
│
├── DiskCleanerLog/                # Auto-created folder that stores every
│                                   timestamped log file generated by a run
│
├── README.md                      # This file
└── .gitignore                     # Excludes logs, cache files, and secrets
```

**Purpose of each module:**
- `Auto_Disk_Cleaner.py` reads and validates command-line arguments, creates
  the log directory, runs the cleaning cycle once immediately, then schedules
  it to repeat automatically.
- `DuplicateFileRemovalUtils.py` contains no execution logic of its own — it
  only defines functions that `Auto_Disk_Cleaner.py` imports and calls.

## 6. Command-Line Options

| Argument | Description |
|---|---|
| `DirectoryPath` | Absolute path of the directory to scan and clean |
| `IntervalInMinutes` | How often (in minutes) the cleaning cycle should repeat |
| `ReceiverEmail` | Email address that will receive the log report after each run |

## 7. Execution Command

```bash
python3 Auto_Disk_Cleaner.py /home/rushi/Downloads 30 youraddress@gmail.com
```

This scans `/home/rushi/Downloads`, repeats every 30 minutes, and emails the
log report to `youraddress@gmail.com` after each run.

## 10. Log-File Information

- Log files are stored inside the `DiskCleanerLog/` folder, which is created
  automatically in the current working directory if it doesn't already exist.
- Each run generates a **new** log file, named using the exact date and time
  the run started, so previous logs are never overwritten:
  ```
  DuplicateRemoveLog_30_07_2026_17_11_02.log
  ```
- Each log file contains: starting time, directory scanned, empty-file cleanup
  details, duplicate-detection details (checksums, kept file, deleted files),
  total files scanned, total duplicates found/deleted, completion time, and
  the email delivery status.

## 11. Email Configuration

The script sends email using Gmail's SMTP server (`smtp.gmail.com`, port 465,
SSL). Gmail requires an **App Password** rather than your regular account
password for SMTP login.

**To generate one:**
1. Go to your Google Account → Security → 2-Step Verification (must be enabled)
2. Go to **App Passwords** → generate a new one for "Mail"
3. Copy the 16-character password Google gives you

**Do not hardcode this password directly in the script**, especially if the
code will be pushed to a public repository. Instead, set it as an environment
variable:

```bash
export GMAIL_APP_PASSWORD="your16charapppassword"
```

And read it in the script:
```python
import os
AppPassword = os.environ.get("GMAIL_APP_PASSWORD")
```

## 12. Important Notes

- **Deleted files may not be recoverable.** Once a duplicate file is removed
  with `os.remove()`, it does not go to a recycle bin — it is permanently
  deleted from disk.
- **Test on a sample directory first.** Before running this against important
  data, create a test folder with a few intentional duplicate files and
  confirm the results match your expectations.
- **Email passwords should never be hard-coded** in a script that will be
  committed to version control. Use an environment variable or a
  `.gitignore`-excluded config file instead.
- **The first file in each duplicate group is always preserved** — the
  remaining files with the same checksum are the ones deleted.
- **Files are only considered duplicates when their MD5 checksums are
  identical** — filenames are never used to determine duplication, since two
  files can have completely different names but identical content (or the
  same name with different content).
- The script runs indefinitely once started; press `Ctrl+C` in the terminal
  to stop the scheduler gracefully.
