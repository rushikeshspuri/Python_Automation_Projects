# Python Automation Projects

This repository contains Python automation projects developed to automate common system tasks and improve productivity.

## Projects

### 📧 Gmail Mail Sender
- Sends emails using Gmail SMTP.
- Supports scheduled email delivery.
- Uses App Password authentication.

### 💾 Automatic Disk Sanitizer
- Identifies and removes unwanted files to help free disk space.
- Automates cleanup tasks.

### 🖥️ Automated Platform Surveillance
- Monitors running processes.
- Generates logs for process activity.
- Useful for basic system monitoring.

## Technologies Used
- Python
- smtplib
- schedule
- psutil
- os
- sys
- time
